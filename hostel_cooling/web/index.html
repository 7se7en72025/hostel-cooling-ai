    How the fit works

    The app uses the first 80% of the readings to estimate how quickly the room gains, loses and stores heat. It checks the estimate against the final 20% and saves the fitted settings to this profile. 

    python -m hostel_cooling calibrate data/noisy_pilot.csv

    Synthetic recovery checks software. Field validation needs measured data and calibrated sensors.
